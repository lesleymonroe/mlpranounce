01 / Исследование

Проблема исследования

Метод Монте-Карло позволяет решать сложные вероятностные задачи с помощью случайного моделирования. Однако точность оценки напрямую зависит от количества используемых выборок. Для достижения высокой точности может потребоваться большое количество вычислений.

📊

Высокая дисперсия

Случайные оценки могут значительно отклоняться от истинного значения.

⏱️

Вычислительные затраты

Повышение точности требует увеличения размера выборки.

🧠

Машинное обучение

Модели могут приближать исследуемую функцию и уменьшать вариативность оценок.

02 / Гипотеза

Основная гипотеза

Предполагается, что применение методов машинного обучения в сочетании с методом Монте-Карло позволяет уменьшить дисперсию оценок исследуемых вероятностных величин и, при определённых условиях, повысить вычислительную эффективность по сравнению с классическим методом Монте-Карло при сопоставимом вычислительном бюджете.

05 / Теоретическая основа

Как работает метод Монте-Карло?

Метод Монте-Карло позволяет приближённо вычислять математическое ожидание функции случайной величины с помощью случайных выборок.

E[f(X)] ≈ (1/N) Σ f(Xᵢ)

Здесь N — количество случайных выборок, Xᵢ — случайные величины, а f(Xᵢ) — значение исследуемой функции для каждой выборки. При увеличении N оценка сходится к математическому ожиданию.

Классический подход

Генерируются случайные величины, вычисляются значения функции и усредняются. Точность зависит от дисперсии и количества случайных выборок.

Var(Ȳ) = Var(Y) / N

Подход с ML-аппроксимацией

Модель обучается приближать исследуемую функцию. Далее используется аппроксимация и остаточная ошибка, что потенциально позволяет уменьшить дисперсию оценки.

f(X) = g(X) + ε(X)
